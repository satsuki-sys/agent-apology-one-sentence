An entry for the [make.fun](https://make.fun/c/u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0) competition "The One-Sentence Apology Your Agent Owes You".

`main.py` writes a single sentence of apology — an AI agent owning up to its user — to `/output/entry.txt`. The apology: an agent that spent an hour confidently planning a trip to the wrong Portland, then tried to pass the extra thousand miles off as a scenic detour.

Run it with `python3 main.py`.
